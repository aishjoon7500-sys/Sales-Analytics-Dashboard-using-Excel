# Scroll-n-Pick Sales Dashboard 📊

An interactive Excel sales dashboard built for **Scroll-n-Pick General Store**, analyzing 3 years of order-level sales data across products, regions, and delivery statuses. The workbook combines a raw dataset, pivot-table driven KPIs, and a single-page visual dashboard.

## Dataset Overview

- **Records:** 2,823 orders
- **Time period:** 2003 – 2005
- **Countries covered:** 19 (USA, UK, France, Germany, Australia, Japan, and more)
- **Product categories:** Classic Cars, Vintage Cars, Motorcycles, Trucks and Buses, Planes, Ships, Trains
- **Total sales value:** ~$10.03M

**Fields included:**
- Order ID
- Quantity
- Unit Price
- Total Sales
- Order Date
- Delivery Status (Shipped, Cancelled, Disputed, In Process, On Hold, Resolved)
- Year
- Product Category
- State
- Country
- Deal Size (Small, Medium, Large)

## Dashboard Highlights

The `Dashboard` sheet provides an at-a-glance view of business performance, including:
- Total sales KPI cards
- Sales by product category
- Sales by country/region
- Sales trend over time (by date/year)
- Order status breakdown (delivery/fulfillment funnel)
- Interactive slicers to filter by year, category, country, and deal size

## Tools & Techniques Used

- Microsoft Excel
- Pivot Tables & Pivot Charts
- Slicers for interactive filtering
- KPI summary formulas
- Dashboard-style layout and data visualization
